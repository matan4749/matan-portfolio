## ✨ Features

- 🌍 **Bilingual** — English / Hebrew (עברית) with full RTL support
- 🌙 **Dark theme** — Deep navy/cyan color scheme with glowing accents
- 💼 **Experience timeline** — RPA Developer at HMS, IDF service
- 🛠️ **Tech Stack grid** — C#, Python, JS, TS, React, Node.js, Next.js
- 🚀 **Featured Projects** — Room 8, ShopHub, and more
- 💬 **Contact section** — Direct links to GitHub, LinkedIn, email, phone
- ⚡ **Fast** — Next.js 16 with Turbopack

<br/>

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 16 (App Router) |
| Language | TypeScript 5 |
| Styling | CSS Modules / Tailwind |
| i18n | Custom translations (EN / HE) |
| Deployment | Vercel |

<br/>

## 🚀 Getting Started

```bash
git clone https://github.com/matan4749/matan-portfolio.git
cd matan-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

<br/>

## 📁 Project Structure

```
matan-portfolio/
├── app/              # Next.js App Router pages
├── components/       # Reusable UI components
├── contexts/         # React context (language, theme)
├── translations/     # EN / HE translation strings
└── public/           # Static assets & images
```
